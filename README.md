# Users & Products CRUD API

## Description
A RESTful API built using Node.js and Express.js for managing users and products.

## Technologies Used
- Node.js
- Express.js

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/HamzaShawky/users_products_CRUD.git
   ```

2. Navigate to the project directory:

   ```bash
   cd users_products_CRUD
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure your environment variables in a `.env` file.

5. Start the server:

   ```bash
   npm start
   ```

## Features
- User management
- Products management
- RESTful API endpoints
- CORS configuration
